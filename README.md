# Homebrew tap

```sh
brew install --cask firstfu/tap/docklens
brew install --cask firstfu/tap/liftoff
```

[DockLens](https://github.com/firstfu/DockLens-app) is a free, open-source (GPLv3) menu bar app for macOS 26+ that shows live thumbnails of all of an app's windows when you hover its Dock icon.

DockLens is **not notarized yet**, so Homebrew cannot remove macOS's first-launch block for you: open System Settings > Privacy & Security and click **Open Anyway** once. This tap is a personal tap (not part of homebrew/cask) and the version here is updated by hand after each release.


[Liftoff](https://github.com/firstfu/Liftoff) is a free, open-source (GPLv3) Launchpad replacement for macOS 26+: the classic grid with live window previews and Smart Organize. It is also **not notarized yet**, so the same one-time **Open Anyway** applies. Its cask is updated by hand after each release too.
